# Pixora

챗봇 썸네일처럼 이미지 몇 장을 겹쳐 한 장으로 만드는 일에 쓰는 작은 웹 이미지 편집기입니다.
설치, 빌드, 서버가 필요 없고, 이미지는 브라우저 밖으로 나가지 않습니다.

**[▶ 바로 열기](https://htmlpreview.github.io/?https://github.com/sisayousm-beep/pixora/blob/main/index.html)**

## 사용법

휴대폰 화면에 맞춘 어두운 편집 화면입니다. 위쪽은 캔버스, 아래쪽은 **레이어 / 비율 / 내보내기** 탭 패널입니다.

1. `index.html`을 브라우저로 엽니다.
2. 오른쪽 위 이미지 버튼으로 이미지를 불러옵니다. 여러 장을 한 번에 불러올 수 있고, 데스크톱에서는 끌어다 놓아도 됩니다.
3. 캔버스에서 이미지를 끌어 옮기고, 모서리 네모를 끌어 크기를 바꿉니다. 원본 비율은 유지됩니다.
4. **레이어** 탭
   - 목록에서 이미지를 선택합니다. 목록 위쪽이 맨 앞입니다.
   - **속성**의 X, Y, W, H에 숫자를 입력해 위치와 크기를 정확히 맞춥니다. W와 H는 비율을 유지합니다.
   - **앞으로 / 뒤로**로 순서를 바꾸고, **삭제**로 지웁니다.
5. **비율** 탭에서 1:1, 4:3, 16:9, 9:16, 3:4 중 하나를 고릅니다.
6. **내보내기** 탭에서 **WebP로 저장**을 누르면 `thumbnail.webp`가 내려받아집니다.

위쪽의 화살표 버튼으로 실행 취소와 다시 실행을 할 수 있습니다.

## 알아둘 점

- 출력 크기는 긴 변 1280px입니다. WebP 화질은 0.9로 고정입니다.
- 이미지로 덮이지 않은 영역은 투명하게 저장됩니다.
- WebP 저장은 Chrome, Edge, Firefox(Android 포함)에서 동작합니다. iPhone/iPad의 브라우저는 모두 Safari 엔진이라 WebP 저장이 안 될 수 있고, 그 경우 안내 메시지가 나옵니다.
