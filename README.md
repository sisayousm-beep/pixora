# Pixora

챗봇 썸네일처럼 이미지 몇 장을 겹쳐 한 장으로 만드는 일에 쓰는 작은 웹 이미지 편집기입니다.
설치, 빌드, 서버가 필요 없고, 이미지는 브라우저 밖으로 나가지 않습니다.

## 사용법

1. `index.html`을 브라우저로 엽니다.
2. **이미지 불러오기**를 누르거나 이미지 파일을 화면에 끌어다 놓습니다. 여러 장을 한 번에 불러올 수 있습니다.
3. **비율**을 고릅니다: 1:1, 4:3, 16:9, 9:16, 3:4
4. 캔버스에서 이미지를 끌어 옮기고, 선택한 이미지의 오른쪽 아래 네모를 끌어 크기를 바꿉니다.
5. 오른쪽 **레이어** 목록에서 ▲/▼로 앞뒤 순서를 바꾸고, ✕로 지웁니다. 목록 위쪽이 맨 앞입니다.
6. **WebP로 저장**을 누르면 `thumbnail.webp`가 내려받아집니다.

## 알아둘 점

- 출력 크기는 긴 변 1280px입니다. WebP 화질은 0.9로 고정입니다.
- 이미지로 덮이지 않은 영역은 투명하게 저장됩니다.
- WebP 저장은 Chrome, Edge, Firefox에서 동작합니다. Safari는 WebP 저장을 지원하지 않아 안내 메시지가 나옵니다.

## 테스트

[Playwright](https://playwright.dev)가 설치된 환경에서:

