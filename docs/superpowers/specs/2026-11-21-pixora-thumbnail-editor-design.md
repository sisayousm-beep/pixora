# Pixora 설계 메모: 챗봇 썸네일 편집기

## 목적
챗봇 썸네일을 만들 때마다 Canva를 여는 게 번거로워서, 그 용도만 하는 작은 오픈소스 웹 이미지 편집기를 만든다.

## 목표 (사용자가 말한 것)
1. 이미지를 여러 장 불러온다.
2. 이미지의 겹침 순서(어떤 것이 위에 올지)를 바꾼다.
3. 캔버스 비율을 고른다(프리셋).
4. 완성한 썸네일 한 장을 WebP로 저장한다.

## 비목표 (보류)
- 텍스트 넣기, 배경색
- 여러 장 일괄 저장
- 도형, 템플릿, 계정, 서버, 프로젝트 저장 등 Canva식 기능

## 안티 목표
- 기능이 늘어나 "작고 빠른 도구"라는 성격이 사라지는 것
- 설치나 빌드 과정이 필요해서 열자마자 쓸 수 없는 것

## 제약
- 웹앱(브라우저에서 동작). 서버 없음, 이미지는 브라우저 밖으로 나가지 않는다.
- 오픈소스로 공개한다. 라이선스는 아래 "내가 정한 기본값" 참고.

## 내가 정한 기본값 (사용자가 확정한 것이 아니므로 검토 필요)
- **기술**: 순수 HTML + JavaScript + Canvas. 프레임워크와 빌드 과정 없이, 파일을 열면 바로 동작한다. WebP 저장은 `canvas.toBlob('image/webp')`로 처리한다.
- **구조**: `index.html` 하나 (JS와 CSS 포함).
- **비율 프리셋**: 1:1, 4:3, 16:9, 9:16, 3:4
- **이미지 불러오기**: 파일 선택과 드래그&드롭
- **순서 조절**: 레이어 목록에서 "위로 / 아래로" 버튼. 드래그 정렬은 하지 않는다.
- **이미지 배치**: 불러온 이미지를 캔버스에서 드래그해 이동하고 크기를 조절한다. 이 기능 없이는 썸네일을 구성할 수 없어서 포함한다.
- **WebP 화질**: 0.9 고정 (조절 UI 없음)
- **라이선스**: MIT

## 구현자에게 맡기는 것
- 화면의 세부 배치와 스타일
- 이미지 이동·크기 조절의 구체적 조작 방식
- 저장 파일명

## 확인되지 않은 것
- 비율 프리셋 목록이 실제로 필요한 비율과 맞는지
- 이미지 삭제 기능의 필요 여부 (기본값: 포함, 레이어 목록에 삭제 버튼)
